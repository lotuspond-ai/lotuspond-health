LotusPond Health anatomy models
===============================

anatomy-female.glb and anatomy-male.glb are adapted from:

- HuBMAP Human Reference Atlas, 3D Reference Object Library, release v2.0, CC BY 4.0
  (https://creativecommons.org/licenses/by/4.0/). Made with data from the Visible Human Male and Female,
  provided by the U.S. National Library of Medicine.
  - Kristen Browne; Heidi Schlehlein. 2023. 3D Reference Organ Set for Female, v1.5. HuBMAP.
    https://doi.org/10.48539/HBM352.BTSQ.586
  - Kristen Browne; Heidi Schlehlein. 2023. 3D Reference Organ Set for Male v1.5. HuBMAP.
    https://doi.org/10.48539/HBM646.RKKC.257
  - Kristen Browne; Heidi Schlehlein. 2023. 3D Reference Organ for Brain, Female v1.3 and Male v1.3.
    https://doi.org/10.48539/HBM425.NDKM.969 and https://doi.org/10.48539/HBM929.XKCL.339
    Made from the Allen Human Reference Atlas - 3D, 2020 (Ding et al., 2016, https://doi.org/10.1002/cne.24080).
  - Kristen Browne, Heidi Schlehlein, Bruce W. Herr II, Ellen Quardokus, Andreas Bueckle, Katy Borner. 2023.
    HuBMAP CCF 3D Reference Object Library. https://humanatlas.io/3d-reference-library

- Z-Anatomy, by Gauthier Kervyn and Lluis Vinent, CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).
  https://github.com/LluisV/Z-Anatomy
  Based on BodyParts3D, (c) The Database Center for Life Science, licensed under CC BY-SA 2.1 Japan
  (https://creativecommons.org/licenses/by-sa/2.1/jp/). https://lifesciencedb.jp/bp3d/

Changes: the Z-Anatomy structures were registered (moved, scaled and warped) to each Visible Human body; some organ
surfaces were rebuilt as closed shapes; reference points, lymph nodes and pregnancy structures were removed; the meshes
were simplified and grouped into organs, with organ and tissue names in each node's extras (the files have no
materials: the app colours each tissue when it draws them). The pre-rendered body map images (bodymap/) are renders
of these models. tools/anatomy/ in the LotusPond Health source builds them from the pinned sources in
tools/anatomy/sources.json.
